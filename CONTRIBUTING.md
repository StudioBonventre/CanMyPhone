# Contributing to CanMyPhone

Thanks for helping people discover what their phones can already do.

## High-value contributions

- add a verified phone capability
- improve compatibility metadata
- correct outdated setup steps
- add Android equivalents to iOS capabilities (or vice versa)
- improve matching aliases for real-world user phrasing
- improve accessibility and localization

## Capability contribution checklist

A capability should include:

1. a concrete user problem or goal
2. a plain-language title
3. platform and compatibility metadata
4. short setup steps
5. cost / built-in status
6. at least one authoritative source URL
7. aliases that reflect how a normal person might ask for it

Do not add a capability based only on an AI-generated claim. Verify it first.

## Pull requests

Keep PRs focused. Dataset-only PRs are welcome and intentionally easy to review.
