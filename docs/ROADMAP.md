# Roadmap

## v0.1 — Foundation
- public open-source repository
- source-backed capability schema
- deterministic intent matching
- first verified iPhone capabilities
- basic Ask experience

## v0.2 — Relevant, not random
- expand to ~50 verified iPhone capabilities
- add Discover for me flow
- add explicit feedback: Worked / Didn't work / Already knew this / Not relevant
- basic local preference profile
- Need Radar On/Off + Clear controls
- learn from queries, opened solutions and explicit feedback
- suppress already-known/not-relevant suggestions
- first proactive "Picked for you" ranking
- distinguish device / OS compatibility

## v0.3 — Conversation + Siri routing
- natural requests such as “Wie mach ich … an?”
- semantic intent classes: enable / how-to / automation / voice-control / availability
- one-question clarification flow for ambiguous requests
- entity detection for apps/devices/services
- Siri direct vs Siri + Shortcuts vs Siri AI routing
- region-aware Siri AI availability and fallback behavior
- first Tesla + Siri/App Shortcut example
- multilingual intent understanding (DE/EN first)
- confidence thresholds and safe no-answer behavior

## v0.4 — Drop Experience
- Liquid Glass Drop avatar with accessibility fallbacks
- semantic haptics for dive / emerge / answer / step
- persistent guided setup session
- AppState-based return/resume flow after switching to Settings
- verified Settings breadcrumbs
- public-only settings navigation policy
- Live Activity / Dynamic Island guide using `expo-widgets`
- EAS development build configuration
- persistent local Need Radar profile

## v0.5 — Community knowledge graph
- remote capability dataset
- schema validation in CI
- contributor review workflow
- source freshness checks
- Android capability expansion

## v0.6 — Advanced opt-in learning
- anonymous aggregate problem-gap analytics
- optional synced user profile
- persistent on-device Need Radar profile
- personalized discovery based on explicit interests and feedback
- transparent "Why am I seeing this?" explanations
- optional cross-device profile sync
- never require broad device surveillance to personalize

## Later
- safe deep links into supported settings when platforms permit it
- installable Shortcut / routine templates
- richer App Shortcut discovery
- app and web-tool recommendations
- partner / affiliate layer with strict sponsored labeling
- public problem-gap dashboard for open-source contributors
